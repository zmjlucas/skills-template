# 中文技能模板

此技能提供可复制的最小结构，尚未实现业务功能。

## 调用时的行为

用户主动调用此技能时，只返回下面这一行纯文本，然后结束：

此技能尚未实现，仅为占位模板。

响应不包含引号、Markdown 格式、解释或提问。占位流程不调用工具，
不读取或修改文件，也不执行用户附带的业务请求。

## 开发者替换说明

此节供开发者改写模板时参考，不属于调用时执行的流程。

1. 将目录名与 frontmatter 中的 `name` 改为实际技能名称，使用小写字母、数字和连字符。
2. 用真实用途替换 `description`，同步修改 `agents/openai.yaml` 中的显示名称、简介和 `$技能名称` 调用示例。
3. 用实际的输入要求、执行流程和输出约定替换占位行为；只在需要时添加 `scripts/`、`references/` 或 `assets/`。
4. 保留技能内的 `LICENSE` 和已有版权声明。此仓库默认仅支持用户主动调用；保留两份元数据中的调用策略。

改写完成后可删除此说明节。版本与发布记录由仓库根目录统一维护。
